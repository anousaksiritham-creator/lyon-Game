# Lyon — Little House

A Lao-language house decorating game for children aged 6+. Tap to choose wall and roof colors, doors, windows and garden decorations. No timers, scores, accounts, ads, or dependencies.

## Play locally

Open `dist/index.html` in a modern browser, or run `npm start` and visit http://127.0.0.1:4173.

## Features

- Large touch controls and responsive layout
- Keyboard controls, focus indicators, reduced motion support
- Undo and reversible reset
- Optional synthesized sounds (off by default)
- Browser-local saving where storage is available
- Download the finished house as an SVG picture

Run `npm run check` for JavaScript syntax checks. Deploy the `dist` folder to any static host. No build step is required.
